# 石門・校園漫遊

桃園市龍潭區石門國民小學的 3D 校園探索原型。

🎮 **開始遊玩：https://cagoooo.github.io/shimen-campus-game/**

電腦：WASD 移動、滑鼠環視、空白鍵跳躍、Q 遊具、E 景點介紹、Esc 暫停。

手機：支援橫直式，左下搖桿移動、右側滑動環視，右下互動／跳躍／慢跑。

首次開啟約需下載 29 MB（實際傳輸量），建議使用 Wi-Fi；使用支援 WebGL 2 的新版瀏覽器。低效能裝置可能較慢。挑戰與聲音設定保存在目前瀏覽器。

本儲存庫為 Godot Web 發布成品；場景為依照片重建的探索原型，比例仍持續校正。公開版未包含校園原始照片、配置原圖與照片貼圖；本機版保留實景對照。校園作品未以開源授權釋出。第三方字型及模型授權請見 NOTO-LICENSE.txt、KENNEY-LICENSE.txt；Godot 引擎授權：https://godotengine.org/license/。
